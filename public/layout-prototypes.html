Concept A

Card Grid with Editorial Lead

The first place gets a full-width hero card. Remaining places in a 2-column grid. Each card has a gradient header with a large decorative number. Feels like a magazine feature or Airbnb Guide.

Concept B

Postcard Collection

A masonry grid where each place is a postcard with a colored accent stripe. Cards vary in height based on content. Subtle tilts make it feel pinned to a board. Screenshottable and playful.

Concept C

Stacked Feature Cards
